## How It Works

### Built-In Messaging System

CalcVault has a **persistent messaging engine** that:

1. ✅ **Stores device IDs** after pairing
2. ✅ **Remembers encryption keys** locally
3. ✅ **Works offline** (queues messages)
4. ✅ **Syncs automatically** when online
5. ✅ **Never expires** (no re-pairing needed)

### Message Flow

```
You send message
    ↓
Encrypted with shared key
    ↓
Sent to relay server
    ↓
Partner's phone polls server
    ↓
Message received
    ↓
Decrypted with shared key
    ↓
Partner sees message ✅
```
